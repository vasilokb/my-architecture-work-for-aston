## Описание архитектуры страховой фабрики для российского рынка

### **Назначение системы**
Фабрика создает и рассчитывает страховые продукты для российского рынка. Она обеспечивает:
- Подбор подходящих клиенту страховых продуктов
- Расчет стоимости страховки (премии)
- Проверку данных через госреестры
- Соблюдение требований ЦБ РФ

### **Основные компоненты и их функции**

#### 1. **Регуляторные справочники** (Обязательные для работы)
- **Коды ЦБ РФ (564-И)** - официальные коды видов страхования (11 цифр)
- **ОКВЭД2** - коды видов экономической деятельности страховщика

#### 2. **Каталог продуктов** (Что продаем)
- **Вид страхования** - например: "Автострахование" или "Медицинское страхование"
- **Шаблон продукта** - конкретный продукт: "ОСАГО", "КАСКО", "ДМС"
- **Программа** - вариант продукта: "Стандарт", "Премиум", "Эконом"
- **Покрытие (риск)** - что именно страхуем: "Ущерб", "Угон", "Медрасходы"

#### 3. **Тарифная модель** (Как считаем стоимость)
- **Тарифная модель** - правила расчета для каждого продукта
- **Ставки ЦБ РФ** - обязательные тарифы для ОСАГО и других регулируемых видов
- **Факторы тарификации** - параметры для расчета: возраст, стаж, регион, мощность авто и т.д.

#### 4. **Внешние интеграции** (Обязательные проверки)
- **Госреестры** - ЕАИСТО (история водителей), ГИБДД (данные ТС), ФНС (юрлица)
- **Сервисные партнеры** - СТО, клиники, оценочные компании
- **Платежные системы** - для приема оплаты

#### 5. **Рабочие объекты** (Что создаем в процессе)
- **Запрос расчета** - входные данные от клиента
- **Рассчитанный продукт** - продукт с учетом всех проверок
- **Результат расчета** - итоговая стоимость и условия

#### 6. **Сервисы фабрики** (Как работает)
- **Фабрика продуктов** - подбирает подходящие продукты клиенту
- **Сервис расчета** - считает стоимость страховки
- **Правила тарификации** - выбирает правильную тарифную модель
- **Андеррайтинг-движок** - проверяет риск и принимает решение

### **Как работает процесс продажи**

#### Шаг 1: Подбор продукта
```
Клиент вводит данные → Фабрика продуктов подбирает доступные варианты
```

#### Шаг 2: Расчет стоимости
```
Выбранный продукт → Сервис расчета → Проверка в госреестрах → Итоговая цена
```

#### Шаг 3: Проверка риска
```
Данные клиента → Андеррайтинг-движок → Автоматическая проверка → Решение
```

#### Шаг 4: Оформление
```
Одобренный расчет → Генерация договора → Оплата → Выпуск полиса
```

### **Примеры российских продуктов**

#### **ОСАГО** (Обязательное страхование)
- **Код ЦБ:** 09.01
- **Тарифы:** Устанавливает ЦБ РФ (Приказ №750-П)
- **Проверки:** ЕАИСТО (КБМ), ГИБДД (данные ТС)
- **Расчет:** Базовая ставка × коэффициенты

#### **Ипотечное страхование**
- **Виды:** Имущество (05.01) + Ответственность застройщика (08.01)
- **Тарифы:** Регулируется ЦБ РФ (Приказ №659-П)
- **Проверки:** Росреестр (права на недвижимость)

#### **ВЗР** (Выезжающие за рубеж)
- **Код ЦБ:** 03.02
- **Тарифы:** Свободные (устанавливает страховщик)
- **Особенности:** Зависит от страны, срока, возраста

### **Требования регуляторов (ЦБ РФ)**

#### Обязательные для всех страховщиков:
1. Использование кодов ЦБ РФ для видов страхования
2. Интеграция с ЕАИСТО для ОСАГО
3. Соблюдение утвержденных тарифов для регулируемых видов
4. Ведение реестра договоров

#### Особенности для разных продуктов:
- **ОСАГО:** Только утвержденные ЦБ тарифы
- **ДМС:** Требуется лицензия на медстрахование
- **ИСЖ/НСЖ:** Отдельные требования к резервам

### **Архитектурные преимущества**

#### Гибкость:
- Новый продукт = новая конфигурация в каталоге
- Не требует изменений кода для новых тарифных планов

#### Соответствие требованиям:
- Все проверки через центральный интегратор
- Аудит всех расчетов и решений

#### Масштабируемость:
- Поддержка разных каналов продаж (веб, агент, банк)
- Интеграция с партнерами и агрегаторами

### **Технические детали**

#### Хранение данных:
- Каталог продуктов - база данных конфигураций
- История расчетов - для аудита и анализа
- Интеграционные токены - результаты проверок в реестрах

#### API для интеграции:
- Внешние системы → API Gateway → Сервисы фабрики
- Поддержка REST/JSON для партнеров
- WebSocket для реальных обновлений

Эта система используется российскими страховыми компаниями для продажи и расчета страховых продуктов с соблюдением всех регуляторных требований.
