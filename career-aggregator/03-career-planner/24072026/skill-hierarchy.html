Колонка group — к какой категории относится навык (Базы данных, Языки, Фреймворки, DevOps...).
Колонка skill — canonical-название (одно на навык, как в HH).
Колонка aliases — синонимы через точку с запятой. Если HH пишет "postgres", а в skill написано "PostgreSQL" — это один навык.
Колонка weight — вес навыка в матчинге. Redis и ClickHouse — обе "Базы данных", но Redis ближе к PostgreSQL, чем ClickHouse.

Как таблицы соединяются в рантайме

В коде: берём вакансию, режем key_skills по точке с запятой, каждый навык ищем в таксономии.
🔧 Что делает код (services.py)
Шаг Что происходит Пример
1 Берём навыки вакансии из колонки D "Python; PostgreSQL; FastAPI; Docker; Redis"
2 Режем по ; ["Python", "PostgreSQL", "FastAPI", "Docker", "Redis"]
3 Каждый ищем в Таблице 1 (таксономии) по колонке skill и aliases "Python" → group: Языки
"PostgreSQL" → group: Базы данных
"Docker" → group: DevOps
"FastAPI" → group: Фреймворки
"Redis" → group: Базы данных
4 Теперь знаем: вакансия требует навыки из групп Языки, Базы данных, Фреймворки, DevOps
5 Сравниваем с навыками кандидата (он тоже выбирал из таксономии, с уровнями) Кандидат знает PostgreSQL (уровень 3) из группы Базы данных
Вакансия требует PostgreSQL из группы Базы данных
→ точное совпадение, 100%

Кандидат НЕ знает ClickHouse, но знает PostgreSQL — обе из группы Базы данных
→ косвенное совпадение, 30%
Итого: две таблицы в одном Google Sheets. skill_taxonomy (заполняем мы) + vacancies (выгружает лабпроект). Код читает обе через gspread, соединяет по названию навыка, сравнивает группы для определения косвенных совпадений.
